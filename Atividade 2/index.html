    Esse código define uma função que imprime um padrão de asteriscos em forma decrescente: a cada linha, a quantidade de * diminui até chegar a zero.

                    def imprimir_padrao(num_linhas):
                    for i in range(num_linhas):
                        for num_colunas in range(num_linhas-i):
